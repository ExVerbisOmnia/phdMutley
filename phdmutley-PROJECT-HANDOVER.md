## 1. Inferred Overview

Pipeline de pesquisa doutoral que processa **16.352 documentos** jurídicos da base Climate Case Chart (Columbia/Sabin Center) para quantificar **padrões de citação transnacional Norte-Sul** em litigância climática. Combina download de PDFs, extração de texto Markdown, classificação binária decision-vs-other em 6 métodos (rule-based + LLM), extração de citações via LLM (Gemini production / Claude agentic), classificação sixfold (6 tipos direcionais Internacional × Nacional × Member-State), **dimensão funcional Nollkaemper** (aligned/contested/avoided/invoked/dismissed — adicionada na v3 agentic), e visualização em dashboard estático D3.js publicado no GitHub Pages. **Achado central declarado:** 96 % das citações no Global North, 4 % no Global South (razão 29:1) — confirmado em maior detalhe por queries (94,6 % North + 0,96 % South + 4,4 % International na production data).
