Research Context
Background & Framework
▼

Background

This research investigates citation patterns in climate litigation, specifically examining how legal decisions from different jurisdictions cite and reference each other. The study analyzes the flow of legal precedents between the Global North and Global South, mapping the network of climate case citations.

Data Source
Climate Case Chart (Sabin Center)
Analysis Method
LLM-Powered Extraction
Classification
Six-fold Citation Schema
💡
Key Innovations
Novel Contributions
▼
  • ✓ Automated Citation Extraction: Using Claude AI to identify and extract legal citations from unstructured court documents with high accuracy.
  • ✓ Case Matching Algorithm: Fuzzy matching system to link extracted citations to known cases in the Climate Case Chart database.
  • ✓ Six-fold Classification: Novel taxonomy for categorizing citation types based on directionality and regional origin.
  • ✓ Network Visualization: Interactive mapping of citation flows between jurisdictions globally.
📄
Phase 0: Document Classification
Filtering Decisions
▼

The first phase classifies each document in the database to identify which entries represent actual court decisions versus other document types (filings, motions, briefs, etc.). Only confirmed decisions proceed to citation extraction.

LLM Prompt Strategy
Documents are analyzed by Claude to determine if they represent final court decisions, interim rulings, or procedural documents. Classification confidence scores are recorded for quality control.
🔍
Phase 1: Source Identification
Finding Citations
▼

Scans decision texts to identify all legal citations, including case names, court identifiers, and date references. Uses pattern matching combined with LLM understanding to capture various citation formats across jurisdictions.

Phase 2: Metadata Extraction
Structured Data
▼

Extracts structured metadata from each citation including case name, year, court, jurisdiction, and citation purpose. Results are stored in PostgreSQL for further processing.

Extracted Fields 
• cited_case_name: Full case title
• cited_year: Decision year
• cited_court: Court/tribunal name
• cited_jurisdiction: Country/region
• citation_context: Surrounding text
• citation_purpose: How the case is used
🔗
Phase 3: Origin Identification
Case Matching
▼

Links extracted citations to known cases in the Climate Case Chart database using fuzzy matching algorithms. Matches are scored for confidence and manually verified for accuracy.

Matching Algorithm
Uses a combination of exact string matching, Levenshtein distance for fuzzy matching, and semantic similarity for case name variations across languages and legal systems.
📊
Phase 4: Six-fold Classification
Citation Taxonomy
▼

Each citation is classified according to a six-fold schema based on the regional origin of both the citing and cited cases, distinguishing between Global North and Global South jurisdictions.
